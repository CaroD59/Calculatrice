# 🧮 Projet Calculatrice Web (But Éducatif)

Ce projet est une application de calculatrice simple construite avec **HTML**, **CSS** et **JavaScript**. Il a été conçu dans un but d'apprentissage pour comprendre les bases du développement web.

## 🎯 Objectif Pédagogique

Ce projet sert de support pour apprendre à :

- Structurer une interface utilisateur avec **HTML5**.
- Créer un design moderne (Style Neumorphism) avec **CSS3**.
- Gérer la logique mathématique et les interactions avec **JavaScript**.

---

## 🚀 Fonctionnalités

- **Calculs de base** : Addition, soustraction, multiplication et division.
- **Gestion de l'affichage** : Un écran qui se met à jour en temps réel.
- **Bouton DEL** : Permet de corriger une erreur en effaçant le dernier caractère.
- **Bouton Clear** : Réinitialise complètement l'affichage à zéro.
- **Design Réactif** : Une interface élégante avec des effets de relief au clic.

---

## 📁 Structure des fichiers

- `index.html` : Contient la structure des boutons et de l'écran.
- `index.css` : Contient le style visuel et l'agencement (Grid Layout).
- `index.js` : Contient la logique (le "cerveau") de la calculatrice.

---

## 🛠️ Installation et Utilisation

1. Copiez les trois fichiers (`index.html`, `index.css`, `index.js`) dans un même dossier.
2. Ouvrez le fichier `index.html` avec votre navigateur web (Chrome, Firefox, Safari, etc.).
3. Utilisez les boutons pour effectuer vos calculs !

---

## 📜 Clause de non-responsabilité

Ce projet est réalisé à **but strictement éducatif**. Il n'est pas destiné à être utilisé pour des calculs critiques
